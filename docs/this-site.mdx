# About this site

This site runs as a [Docusaurus](https://docusaurus.io/) project hosted on [GitHub](https://github.com/garethpower/portfolio).

Each push triggers a **deploy.yml** script on GitHub Actions containing the following jobs:
* the [Vale](https://docs.vale.sh/) linter reviews the content for issues defined in its rule set
* Lychee checks the validity of external links
* the project builds and deploys to GitHub Pages

In my setup, Vale is configured to enforce Microsoft styles and [write-good](https://github.com/btford/write-good) rules, flagging most issues as warnings rather than errors.

Vale also runs locally in my code editor, so I see its errors and warnings in real time too.

The sample API specification page on this site is generated from YAML by the "redocusaurus" Redoc plugin.

Claude Code saves me a good deal of time with tasks such as configuration, automation, and bulk changes.

Timesheet Errors and Warnings

The TagomiPay system carries out a series of checks on timesheet data.

If it detects any abnormalities, it displays appropriate messages in the Timesheet Entry screen and in the employee's payslip.

The Automatic Timesheets, Batch Timesheet Entry and Timesheet Import windows also display these messages.

You may encounter three types of timesheet message:

Message TypeIconDefinition
Error MessageA timesheet error messages signifies an issue serious enough for the system to prevent you from saving the timesheet until it is resolved.
Warning messageA timesheet warning message signifies that the system has detected an issue you may need to address.
You can still save the timesheet. However, it may be advisable to address the cause of the warning first.
Info MessageTimesheet info messages are intended to provide you with information you may find useful.
You can still save the timesheet. These issues do NOT affect the validity of the timesheet.
Timesheet Error Messages

A timesheet with any of the following error messages cannot be saved until the error is resolved.

Error Message

Meaning
Nett pay is a negative amountThe sum of the PAYE, PRSI and USC deductions (also PRD if applicable) in the current pay period are greater than the total payment values.

As a result the net pay value is negative, and the timesheet cannot be saved.
Disability pay exceeds normal payPayments of type Paid Disability are deducted from the main payment value.
However, in this case the main payment value is lower than the Paid Disability value, and as a result the timesheet cannot be processed.
Formula not set up correctlyA payment or deduction formula seems to contain invalid fields or values.
Holiday payment not setNo holiday payment has been set up in the Company Details - Holidays tab.
Because of this, it is not possible to process holiday pay using the Holiday and Absence Tracking feature.
PRSI code XX no longer validA PRSI code previously applied to the employee is no longer in the PRSI Table.
Already paid up to period XThe employee has already been paid up to pay period X.
The most likely reason is that the employee has received holiday pay in advance.
This employee has already left.The employee was marked as a leaver in a previous pay period.
PRSI code XX improperly definedA PRSI code that applies to the employee has no rates or earning bands associated with it in the PRSI Table.
Nett to Gross payment not setThe Net to Gross feature must reference a specific payment in the Company Details - Misc tab.
No payment is currently referenced there.
Error calculating Payment XA payment cannot be calculated, probably because a value referenced in an associated formula is not set in the current timesheet.
Error calculating Deduction XA deduction cannot be calculated, probably because a value referenced in an associated formula is not set in the current timesheet.
Timesheet not calculatedTimesheet not calculated.
No payments/refunds on timesheetThe current timesheet has no payment values, and no refunds are due. Therefore, the timesheet cannot be saved.
Employee is suspendedThe employee is currently suspended and cannot be paid in the current pay period.
Employee holiday info missingHoliday pay can't be processed for the employee because the information on the employee details record's Holidays tab is incomplete.
EE holiday Hourly Rate not setThe payment associated with the '% of Hours Worked' accrual method references a specific Hourly Rate field.
The current employee has no rate value in that field.
Year's USC a negative amountThe USC total for the tax year is a negative value.
Because of this, the timesheet cannot be saved.
The USC total was probably manually overridden.
Timesheet data not importedThere was a problem with the Timesheet Import data for the specified employee.
As a result their timesheet has not been saved.
Timesheet Warning Messages

A timesheet that has warnings associated with it can still be saved. However, it may be advisable to address the cause of the warning first.

Warning Message

Meaning
Tax refund paid this periodThe employee is receiving a refund of previous tax deductions in the current pay period.
This usually occurs because of a change in the employee's tax allowances, or a reduction in their gross pay in the current period.
Pens Contrib > X % of Gross Pay TDThe total pension / PRSA contributions for the current year are greater than the allowed percentage of the employee's annual gross pay.
(The allowed percentage is determined by the employee's age.)
Employee Std Rate Cut-Off not setThe employee has not been assigned a Standard Rate Cut-Off value.
All of their Gross Pay will be subject to tax at the higher tax rate.
Nett to Gross EE can't have Nett BIKThe employee is being paid on a Nett to Gross basis.
However, there is also a Nett BIK payment on the current timesheet.
Nett BIK cannot be processed for employees paid on a Nett to Gross basis.
EE maximum Nett Pay exceededThe employee's Nett Pay in the current pay period exceeds the maximum value specified on the Employee Details record or in the Company/Payroll Details record.
Nett Pay below EE minimumThe employee's Nett Pay in the current pay period is lower than the minimum value specified in the Employee Details record or in the Company/Payroll Details record.
Ins. Weeks TP reduced to 0The current timesheet has no payment values. Because of this the employee's number of insurable weeks is set to zero in the current pay period.
Reducing deduction exceeded balanceThe balance for a deduction set up with the 'Reducing' balance type has been exceeded.
Zero PayThe current timesheet has no payment values and no refunds due.
Rates below JLC Rate of x.xxOne or more payment rates on the current timesheet is below the recommended JLC rate for the employee.
PRD refund not calc.A recalculation of the current employees PRD contributions is not possible.
This is usually due to the employee not having the full 52 insurable weeks in their current employment.
Nett to Gross value estimatedThe system had to estimate the employees Nett to Gross payment amount.
Other payments are affecting the Nett to Gross calculation.
No table cut-off specifiedThe employee has no Standard Rate Cut-Off Amount.
Cannot recalc EOY Health LevyThis warning message applies to 2010 payrolls only. Budget 2011 abolished the Health Levy.
It applies to the following cases:
• When you save a timesheet with the Health Levy recalculation checkbox selected, but a PRSI Override has been carried out in the current period.
The recalculation cannot be carried out in this pay period for the employee when this is the case.
However, if there is a subsequent pay period in the tax year, the system will attempt to carry out the recalculation again in that period.
The Control Summary will include the following additional information:
"PRSI has been overridden this period."
• When you save a timesheet with the Health Levy recalculation checkbox selected, but a PRSI override was carried out in one or more previous pay periods in the tax year.
The Health Levy recalculation cannot be carried out for the employee when this is the case.
The Control Summary will include the following additional information:
"The system has determined that in one or more previous pay periods PRSI totals may have be overridden."
• When you save a timesheet with the Health Levy recalculation checkbox selected, but the employee was set up in the system during the year through the Mid-Year Employee Setup process.
The Health Levy recalculation cannot be carried out for the employee when this is the case.
The Control Summary will include the following additional information:
"A mid-year setup was completed for this employee."
Cannot recalc EOY Income LevyThis message is displayed when you save a timesheet with the Income Levy recalculation checkbox selected, but a PRSI Override has been carried out in the current period.
The recalculation cannot be carried out in this pay period for the employee when this is the case.
However, if there is a subsequent pay period in the tax year, the system will attempt to carry out the recalculation again in that period.
The Control Summary will include the following additional information:
"PRSI has been overridden this period."
Cannot recalc EOY PRDThis error is displayed when you save a timesheet with the PRD recalculation checkbox selected, but a PRSI Override has been carried out in the current period.
The recalculation cannot be carried out in this pay period for the employee when this is the case.
However, if there is a subsequent pay period in the tax year, the system will attempt to carry out the recalculation again in that period.
The Control Summary will include the following additional information:
"PRSI has been overridden this period."
Timesheet Info Messages

Timesheet info messages are intended to provide you with information you may find useful. These are issues that do NOT affect the validity of the timesheet.

Info Message
Meaning
Employee PPS no. not setThe Employee Details record contains no PPS number.
Without this number the employee's tax may be calculated at the higher rate.
Starting in this periodThe employee is starting in this employment in the current pay period.
PRSI rate locked to base codeThe employee's PRSI is locked to their current PRSI base code.
All PRSI deductions will be calculated at the base code, regardless of their PRSIable pay amount for the current pay period.
This setting should only be selected when recommended by the Dept of Social Protection.
Multiple EmploymentsThis employee has multiple employments.
This precludes any entitlement to PRSI allowances for this employment.
Leaving this PeriodA finish date and a finish period (the current period) has been entered for the employee on the timesheet, or in the Employee Details window.
PAYE value overriddenThe user has adjusted the PAYE value on the current timesheet using the PAYE Override functionality.
Employee PRSI overriddenThe user has adjusted the Employee PRSI value on the current timesheet using the PRSI Override functionality.
Employer PRSI overriddenThe user has adjusted the Employer PRSI value on the current timesheet using the PRSI Override functionality.
Negative Employee PRSIThe Employee PRSI is showing a negative value in the current pay period.
This usually occurs as a result of an Employee PRSI override
Negative Employer PRSIThe Employer PRSI is showing a negative value in the current pay period.
This usually occurs as a result of an Employer PRSI override
Starting and leaving this periodThe employee is starting in this employment in the current pay period, and will also be leaving this employment in the current pay period.
Employee suspended this period.The employee has been flagged to be suspended from the current pay period.
If you need to pay them in this period, you must undo the suspension.
On holidays to period XThe employee is being paid up until Period X in this timesheet.
The Timesheet Entry screen will not subsequently make the employee available for processing until Period X+1.

# Source data

For source content I used a set of publicly available HTML pages that I wrote for [Altify’s Relationship Map Knowledge Base](https://altifyhelp.com/v9.4/Common/RelMap/rel-map-intro.htm)

I chose these pages because it meant I could work with well-understood source content and readily judge the accuracy and quality of the LLM’s answers relating to it.

Having obtained HTML from the URL above, I also prepared plain text, PDF and DITA versions of the content so that I had four different sets of data in the source formats I wanted to test.

(I created a Python script to convert the HTML pages into DITA pages. It should be noted that while this meant I had valid DITA pages to work with, these probably do not make full use of all the capabilities of DITA, so my results may not reflect the full benefits of DITA for RAG.)

Tagomi Commerce API (2.4.0)

Download OpenAPI specification:Download

Tagomi API Support: api-support@Tagomi.example.com URL: https://developers.Tagomi.example.com/support License: Apache-2.0 Terms of Service

Manage products, customers, orders and payments for Tagomi online stores.

The Tagomi Commerce API enables both partners and internal services to manage the full transaction lifecycle in a Tagomi online store.
(This sample API specification was generated by Claude Code. I edited the specification to ensure that the documentation text is clear and concise, but left the original text where it seemed completely acceptable.)

Full developer guide

Conventions

  • All timestamps are RFC 3339 in UTC.
  • All monetary amounts are integers in the currency's minor unit. For example, USD amounts are expressed in cents. Typical example: 1999 = $19.99 USD.
  • Identifiers are opaque, prefixed strings (prd_, cus_, ord_, pay_).
  • Collection endpoints use cursor pagination (see Pagination below).

Rate limiting

Every response carries X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset headers. Exceeding the limit returns a 429 error.

Idempotency

POST requests accept an Idempotency-Key header. Resending a request with the same key within 24 hours returns the original response.

Errors

Errors use application/problem+json as defined by RFC 9457.

Returns a paginated list of products. This can be filtered by category, price range and status. It can be sorted by any sortable field.

object
